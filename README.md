# Calculateur du revenu disponible

Calculateur du revenu disponible des ménages au Québec (2025, 2026 et 2027) : impôts, cotisations et transferts.

**Utiliser le calculateur : <https://boisalai.github.io/revenu-disponible/>**

Ce dépôt ne contient que la version publiée : un site statique, sans serveur, sans compte, où le calcul se fait dans le navigateur. Le guide d'utilisation (`guide-utilisation.html`) et le document technique (`guide-revenu-disponible.pdf`) sont joints.

Outil **pédagogique** : les montants produits sont indicatifs et ne constituent ni un avis fiscal, ni un avis juridique, ni un avis financier.
